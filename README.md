# 더케이 오락실 · 레트로 벽돌깨기

> **최종본 2026-10-21** — Figma 설계서(26.10.21 업데이트, 온라인용) 기준

The-K 콘텐츠 전용관 6편 「벽돌깨기」 프로토타입입니다. 8비트 네온 레트로 스타일의 모바일 웹 게임이며, 설치 없이 브라우저에서 바로 실행됩니다.

## 플레이

- 시작 화면에서 **시작하기** → 화면을 터치(클릭)하면 공이 발사됩니다.
- 바(패들)를 움직여 공을 받아내고 벽돌을 깹니다.
- 떨어지는 **선물**을 받으면 아이템 도감에 등록되고 HP가 30 회복됩니다. 어떤 선물인지 읽을 수 있도록 **선물을 받았을 때만 게임이 잠시 멈추고**, 화면을 클릭(터치)하면 이어서 진행됩니다.
- **폭탄**을 맞으면 HP -25, 공을 놓치면 HP -30입니다. 체력이 깎이는 동안에는 상단·하단 라인과 HP바가 빨강으로, 채워질 때는 HP바 테두리가 초록으로 바뀝니다. 공을 놓쳐도 게임이 멈추지 않고 1초 뒤 공이 자동으로 다시 발사됩니다. HP가 0이 되면 게임 오버입니다.
- 스테이지를 깰 때마다 **벽돌이 한 줄씩 늘고 공 속도가 20%씩 빨라집니다.** (총 3단계, 3단계를 깨면 ALL CLEAR → **한 판 더**)
- 아이템을 3개 이상 모으면 아이템 도감에서 본인인증 후 경품 응모가 열립니다.
- 응모하면 **경품 응모 완료** 화면으로, 이미 응모한 브라우저에서 다시 응모하면 **이벤트 중복 참여 방지**("이미 경품 응모가 완료되었습니다.") 화면으로 이동합니다. (본인인증 연동 전에는 데모로 인증 완료로 간주) 두 화면의 **게임으로 돌아가기**는 스테이지 1로 이동합니다.

| 조작 | 방법 |
|------|------|
| 모바일 | 화면을 좌우로 스와이프 / 짧게 탭하면 발사 |
| PC 마우스 | 첫 클릭으로 시작·발사 후 마우스 좌우 이동 |
| 키보드 | ← → (또는 A D) 이동, Space 발사, M 음악 on/off |

## 구성

```text
index.html              루트 → Btype/ 이동 안내
Btype/index.html        화면 마크업
Btype/css/style.css     8비트 픽셀 UI 스타일 (디자인 토큰)
Btype/js/sprites.js     픽셀 스프라이트 데이터 (덕헤이, 아이콘, 선물/폭탄)
Btype/js/game.js        게임 로직 + 렌더링 + UI 연결
Btype/assets/           네온 도시 배경, 아이템 도감 아이콘 10종
```

> 배포 주소: https://uxui-test-2.github.io/the-K_EP.06/Btype

- 게임 로직(드롭 확률, 스테이지 구성, HP 규칙, 도감 저장 등)은 `KTCU_DS_PMO_PICK_벽돌깨기편_게임_v0.5` 와 동일합니다.
- 화면은 Figma 디자인을 기준으로 제작했습니다. 공 크기(반지름 8), 아이템 크기(48), 패들 높이(16)만 디자인에 맞춰 시각 규격을 조정했습니다.
- 아이템 도감은 브라우저 `localStorage`에 저장됩니다.

## 경품 있음 / 경품 없음 버전

설계서의 분기 처리에 따라 같은 페이지를 두 가지로 쓸 수 있습니다.

| 버전 | 주소 | 동작 |
|------|------|------|
| 경품 있음 (기본) | `Btype/` | 아이템 3개 이상 → 본인인증 후 경품 응모 (본인인증 CRM 연결) |
| 경품 없음 | `Btype/?prize=off` | 도감의 본인인증 버튼과 게임오버·올클리어 팝업의 본인인증 문구가 없음. 도감 하단은 버튼 하나(획득 아이템이 있으면 **닫기**, 없으면 **계속하기**) |

## 응모 결과 화면 (직접 열기)

| 화면 | 주소 |
|------|------|
| 경품 응모 완료 | `?page=complete` |
| 이벤트 중복 참여 방지 | `?page=duplicate` |

본인인증 페이지가 인증 후 이 주소로 되돌려 보내면 됩니다. 응모 여부는 브라우저 `localStorage`(`KTCU_BREAKER_PRIZE_APPLIED_V1`)에 저장됩니다.

## 설정

`Btype/js/game.js` 상단의 `PRIZE_CONFIG`에서 다음을 지정합니다.

- `prizeName`: 경품 이름
- `authUrl`: 본인인증 페이지 주소 (비어 있으면 데모 모드 — 바로 응모 결과 화면으로 이동)
- `savingUrl`: 「장기저축급여 알아보기」 연결 주소 (콘텐츠 전용관 장기저축급여 편)
- `welfareUrl`: 「공제회 회원 전용 혜택 모아보기」 연결 주소 (콘텐츠 전용관 복지혜택 편)

연결 주소가 비어 있으면 버튼을 눌렀을 때 "연결 페이지를 준비하고 있어요." 안내가 표시됩니다.
