# 더케이 오락실 · 레트로 벽돌깨기

The-K 콘텐츠 전용관 6편 「벽돌깨기」 프로토타입입니다. 8비트 네온 레트로 스타일의 모바일 웹 게임이며, 설치 없이 브라우저에서 바로 실행됩니다.

## 플레이

- 시작 화면에서 **시작하기** → 화면을 터치(클릭)하면 공이 발사됩니다.
- 바(패들)를 움직여 공을 받아내고 벽돌을 깹니다.
- 떨어지는 **선물**을 받으면 아이템 도감에 등록되고 HP가 30 회복됩니다.
- **폭탄**을 맞으면 HP -25, 공을 놓치면 HP -30입니다. HP가 0이 되면 게임 오버입니다.
- 아이템을 3개 이상 모으면 아이템 도감에서 본인인증 후 경품 응모가 열립니다. (본인인증 연동은 준비 중)

| 조작 | 방법 |
|------|------|
| 모바일 | 화면을 좌우로 스와이프 / 짧게 탭하면 발사 |
| PC 마우스 | 첫 클릭으로 시작·발사 후 마우스 좌우 이동 |
| 키보드 | ← → (또는 A D) 이동, Space 발사, M 음악 on/off |

## 구성

```text
index.html        화면 마크업
css/style.css     8비트 픽셀 UI 스타일 (디자인 토큰)
js/sprites.js     픽셀 스프라이트 데이터 (덕헤이, 아이콘, 선물/폭탄)
js/game.js        게임 로직 + 렌더링 + UI 연결
assets/           네온 도시 배경, 아이템 도감 아이콘 10종
```

- 게임 로직(드롭 확률, 스테이지 구성, HP 규칙, 도감 저장 등)은 `KTCU_DS_PMO_PICK_벽돌깨기편_게임_v0.5` 와 동일합니다.
- 화면은 Figma 디자인을 기준으로 제작했습니다. 공 크기(반지름 8), 아이템 크기(48), 패들 높이(16)만 디자인에 맞춰 시각 규격을 조정했습니다.
- 아이템 도감은 브라우저 `localStorage`에 저장됩니다.

## 설정

`js/game.js` 상단의 `PRIZE_CONFIG`에서 경품 이름(`prizeName`)과 본인인증 페이지 주소(`authUrl`)를 지정합니다. `authUrl`이 비어 있으면 "연동 준비 중" 안내가 표시됩니다.

## 사용한 폰트·리소스

- 폰트: [Mona12](https://github.com/MonadABXY/mona-font) (jsDelivr CDN), [Pretendard](https://github.com/orioncactus/pretendard) (폴백)
- 이미지: 모두 8비트 도트로 직접 제작한 에셋입니다.
